## 🚀 项目介绍

**企业认证平台（Enterprise Auth Platform）** 是一套基于 **Java 17 + Spring Boot 3 + Sa-Token + MyBatis-Plus** 构建的企业级权限管理平台。系统支持多租户架构，提供完整的用户、角色、菜单、部门等基座模块管理能力。

---

## 🏗 项目架构

- 后端：Spring Boot 3.5 单体架构
- 前端：Vue 3 + Vben Admin v5 + Element Plus
- 数据库：MySQL + Redis

## 📦 系统模块

- 系统管理：用户管理、角色管理、部门管理、菜单管理、在线用户
- 平台管理：租户管理、租户套餐、字典管理、参数管理、分类配置
- 系统监控：操作日志、登录日志
- 工具管理：代码生成、文件管理、邮件配置、公告管理
- 工作流：流程设计器、流程定义、我的发起、我的待办、我的已办
